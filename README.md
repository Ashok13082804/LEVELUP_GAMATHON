PROJECT DESCRIPTION
GAMETHON — The Living AI Universe is an original, next-generation AAA gaming platform and metaverse engine developed by Cold Forge Games.
It integrates 100% offline local artificial intelligence (Ollama LLM, RAG vector memory databases, and Web Speech STT/TTS engines) 
directly into dynamic browser-based interactive gaming. Built with a unified player identity system, GAMETHON allows players to seamlessly
carry forward their progression, inventory items, reputation, skill trees, and NPC memory across multiple game modes. The interface 
utilizes a cyberpunk glassmorphism design system complete with real-time hardware telemetry monitoring (CPU, GPU, FPS, Ping) for a 
responsive gaming experience.

TECH STACKS USED
The project utilizes a modern client-first architecture comprising HTML5 for page structure, Vanilla JavaScript (ES6+) for core game loops, 
state management, and AI engine integrations, and CSS3 featuring custom variables, glassmorphism UI elements, backdrop blurs, and 
flexbox/grid layouts. Renders utilize the HTML5 Canvas API and WebGL for 2D/3D viewports. On the backend/AI layer, it integrates with 
Ollama (Llama 3, Mistral, DeepSeek) for local LLM inference, local FAISS/Vector RAG databases for NPC interaction history, 
Speech Recognition / SpeechSynthesis APIs for voice commands and narration, and LocalStorage / SQLite for persistent player 
progression saves.
